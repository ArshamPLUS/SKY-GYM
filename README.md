# SKY GYM

A modern, responsive website for **Sky Gym**, a men's bodybuilding gym in Fardis, Karaj.

## About

Sky Gym is a promotional website designed to introduce the gym, its services, facilities, pricing, gallery, and contact information.

The website is built with a clean, minimal, black-and-white visual style with a focus on responsive design and smooth user interactions.

## Features

* Responsive design for desktop, tablet, and mobile
* Persian RTL layout
* Modern black-and-white UI
* Hero section with gym photography
* Services and facilities sections
* Pricing plans
* Image gallery
* Google Maps integration
* Instagram and phone contact links
* Scroll reveal animations
* Mobile navigation
* Custom Persian font

## Technologies

* HTML5
* CSS3
* Vanilla JavaScript
* Google Maps Embed
* Vazirmatn
